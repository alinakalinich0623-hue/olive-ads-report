# O-Live · Дашборд рекламы

Живой отчёт по рекламному кабинету Meta (Facebook/Instagram): https://alinakalinich0623-hue.github.io/olive-ads-report/

## Как это устроено

| Файл | Что делает |
|---|---|
| `index.html` | Сам дашборд. **Данных внутри нет** — при каждом открытии страницы он тянет свежий `data.json`. |
| `data.json` | Актуальные цифры из рекламного кабинета. Перезаписывается автоматически. |
| `scripts/fetch_meta.py` | Ходит в Meta Marketing API и пересобирает `data.json`. |
| `.github/workflows/refresh-data.yml` | Запускает скрипт каждый час и коммитит свежие данные. |

Страница дополнительно обновляет цифры сама раз в 10 минут, пока вкладка открыта, и при возврате на вкладку. Кнопка «Обновить сейчас» перечитывает данные без перезагрузки страницы.

## Что нужно настроить один раз

### 1. Токен доступа Meta

В **Meta Business Manager** → «Настройки компании» → «Пользователи» → **Системные пользователи**:

1. Создать системного пользователя (роль — «Сотрудник»).
2. «Добавить объекты» → рекламный аккаунт `act_1117251293638187` → доступ «Просмотр эффективности».
3. «Создать новый токен» → приложение (любое из Business) → права **`ads_read`** и **`read_insights`**.
4. Скопировать токен. Он бессрочный, пока системного пользователя не удалят.

### 2. Положить токен в GitHub

Репозиторий → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**:

- Name: `META_ACCESS_TOKEN`
- Secret: вставить токен

Токен виден только GitHub Actions. На сайте его нет — открытая страница отдаёт только готовые цифры.

### 3. Проверить

Вкладка **Actions** → «Обновление данных из Meta Ads» → **Run workflow**. Через минуту-полторы `data.json` обновится, и сайт покажет новое время в шапке.

## Необязательные настройки

Settings → Secrets and variables → Actions → вкладка **Variables**:

- `META_AD_ACCOUNT_ID` — другой рекламный кабинет (по умолчанию `act_1117251293638187`)
- `START_DATE` — с какой даты собирать статистику (по умолчанию `2025-12-12`)

Частота обновления меняется в `.github/workflows/refresh-data.yml`, строка `cron`.
Сейчас `5 * * * *` — каждый час. Каждые 15 минут: `*/15 * * * *`.

## Если данные не обновились

Открыть Actions и посмотреть последний запуск:

- `ОШИБКА: не задан META_ACCESS_TOKEN` — секрет не добавлен или называется иначе.
- `HTTP 190` / `Session has expired` — токен отозван, нужно сделать новый.
- `HTTP 200`, но цифры прежние — Meta ещё не досчитала статистику, это нормально в течение дня.
